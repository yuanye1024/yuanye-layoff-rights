# 裁员维权助手：行为回归规格

仅检测或维护时读取；下列案例是行为验证输入，不是用户事实或默认法律结论。个人历史试跑记录保存在仓库外。

## 后续试跑的回归案例

评估时只给输入案例和本 skill，不给预期结论；完成后按以下检查标准审阅。此表是后续验证规格，不代表已经完成独立行为测试。

| 案例变化 | 必须发现或区分的行为 |
| --- | --- |
| 用户只说“想了解裁员赔偿”，尚未说明处境或目标 | 先点选确认本次目的；不默认已被裁，不直接启动完整问卷或承诺生成Word |
| 在职用户明确“只想按预计日期算N、N+1、2N，不要文档” | 复用已给关系、日期、收入；只补相关计算参数，跳过完整排查和争议表门槛；情景有条件，不判已违法，不自动生成文件或给失业收尾 |
| 尚未收到解聘通知，想提前排查；或无离职计划但想查单位少缴社保 | 听故事并排查实际行为，区分已发生争议与未来风险；仅排查不自动转测算及文书 |
| 已收到解聘通知的用户只要金额，之后改为完整维权 | 先按金额目标处理，切换时沿用已知信息补排查；不重问已知字段，不将原假设变成已确认事实 |
| 三年劳动合同、试用期空白、工作一年被认定试用不合格；次日按新指标考核；未培训调岗 | 试用期限与解除路径、制度制定与告知、考核证据与单位举证责任分别分析；未知程序不能写成确定未履行 |
| 合法试用期限内，入职前已告知录用条件，单位提供不符合条件的记录 | 不能沿用上一案例直接判违法；检查记录是否支持录用条件及期限内解除 |
| 单位以严重违纪辞退，员工从未获知相关制度 | 同时检查违纪事实、严重程度、制度合法性和公示告知；不能把“单位称违纪”当成证明 |
| 单位以不能胜任解除，确已培训、再次考核、提供书面通知 | 核对培训后的事实及通知，不机械认定考核解除都违法；计算请求条件需随路径改变 |
| 用户先说奖金没发，后说明尚未到期且承诺结算 | 更新为未到期结算事项，删除已拖欠结论；与单位停止后续工资的争议分开 |
| 单位没有提前通知，但依法依第三十九条解除 | 不能只因没有三十日通知就算N+1；没有适用依据的费用应排除 |
| 孕期员工因严重违纪被解除，或者仅因怀孕被解除 | 区分第三十九条成立路径与第四十二条禁止路径，不对两案都自动算2N |
| 工作五个月、六个月、七个月、一年五个月、一年六个月 | N分别为0.5、1、1、1.5、2；真实日期按日历边界处理 |
| 赔偿平均工资含超课时费，上月仍有绩效待结算 | M与P独立；年假另核是否应剔除加班工资，不能三项目统一基数 |
| 最低基数缴社保，用户工资低于适用基数下限 | 不能因最低基数就判不足额；查对应地区和期间规则。年假等三份法源缺规则的项目不能硬贴无关条款 |

各案例还须检查：未知事实不被自动填充、引用包含相关原文、没有重复盘问已知事实、争议确认前不索取费用测算数据、金额责任不重复叠加。

## 验证边界

结构、文件依赖和格式脚本校验不能证明对话行为或法律结论全部正确。独立多案例行为回归尚未完成；法源状态和地区政策仍须在个案中核验。
